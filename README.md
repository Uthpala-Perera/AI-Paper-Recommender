# AI Academic Paper Recommender

An advanced AI-powered research assistant that uses transformer-based semantic search and Retrieval-Augmented Generation (RAG) to recommend and interact with academic papers.

## Features

- Semantic search using Sentence Transformers
- Fast similarity search with FAISS
- AI-powered summaries (BART)
- Ask questions about papers (RAG)
- Save and manage papers
- Analytics dashboard

## Tech Stack

- Python
- Streamlit
- Transformers (Hugging Face)
- FAISS
- Sentence Transformers

## How It Works

1. Papers are collected via arXiv API
2. Text is embedded using transformer models
3. FAISS performs similarity search
4. LLM generates summaries and answers
